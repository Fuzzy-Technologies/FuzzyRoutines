快速入门

室温 24 °C 在多大程度上属于“舒适”？设 22 °C 时隶属度为 1，并在 16 °C 和 28 °C 处降至 0，然后计算测量值的隶属度。

1 · 安装

在项目环境中使用 Python 3.13 或 3.14。

本示例使用 2.0 API。请从 PyPI 安装对应版本；历史版本 1.x 不提供此 API。

终端
python -m pip install fuzzyroutines==2.0.0

2 · 运行示例

将代码保存为 comfort.py，然后执行 python comfort.py。

Python · comfort.py
from fuzzyroutines import (
    ContinuousUniverse, ScalarFuzzySet, Triangle,
)

universe = ContinuousUniverse(
    0, 40, leftClosed=True, rightClosed=True,
)
comfort = ScalarFuzzySet(universe, Triangle(16, 22, 28))
temperature = 24
grade = comfort.Membership(temperature)

print(f"Temperature: {temperature} °C")
print(f"Comfort membership: {grade:.3f}")

3 · 理解结果

预期输出
Temperature: 24 °C
Comfort membership: 0.667

该温度位于三角形的下降段：(28 − 24) / (28 − 22) = 2/3。数值 0.667 表示对舒适温度模糊集的隶属度，而非概率。

这些阈值仅为示例中的建模选择。可以添加其他语言项，以区分应用中的舒适、温暖和炎热状态。
