# Аналитический вывод исторического параболического отрицания {#analytical-derivation-of-the-legacy-parabolic-negation}

- Статус: математический контракт задачи #56
- Связанный ADR: [ADR-0004](../../../../adr/0004-operator-and-negation-contracts.md)
- Историческая функция: `FuzzyNOTParabolic(x, alpha, epsilon)`

## Область действия и терминология {#scope-and-terminology}

Историческая функция задаётся неявным симметричным соотношением

```text
2*alpha - x - y = (2*alpha - 1) * (y - x)**2
```

Здесь выводится его допустимая аналитическая ветвь. Ни один источник, найденный при обзоре,
не устанавливает это точное уравнение как именованное каноническое семейство.
Поэтому проект сохраняет историческое имя `FuzzyNOTParabolic` и не представляет его
как стандартное опубликованное «параболическое отрицание».

Требования к концам интервала, антитонности и инволютивности следуют обычному контракту
сильного нечёткого отрицания; см. формальное изложение нечётких отрицаний
в [Bedregal et al. (2017)](https://arxiv.org/abs/1707.08617).

## Вывод {#derivation}

Пусть `k = 2*alpha - 1` и `d = y - x`. Соотношение принимает вид

```text
k*d**2 + d + 2*(x - alpha) = 0
```

При `alpha != 1/2` ветвь, проходящая через неподвижную точку `(alpha, alpha)`, равна

```text
D = 1 - 8*k*(x - alpha)
d = (-1 + sqrt(D)) / (2*k)
y = x + d
```

Численно устойчивый эквивалент, также дающий непрерывный предел при `alpha = 1/2`:

```text
y = x + 4*(alpha - x) / (1 + sqrt(D))
```

При `alpha = 1/2` выражение точно сводится к `y = 1 - x`.

## Допустимая область параметра {#valid-parameter-domain}

Ветвь через неподвижную точку удовлетворяет `N(0) = 1` только при `alpha >= 1/4`,
а `N(1) = 0` — только при `alpha <= 3/4`. На замкнутом интервале

```text
alpha in [1/4, 3/4]
```

дискриминант неотрицателен при `x in [0, 1]`; выбранная ветвь непрерывна,
монотонно убывает, оставляет `alpha` неподвижной и инволютивна.
Последнее свойство следует из симметрии определяющего соотношения по `x` и `y`
и единственности выбранной допустимой ветви результата.

Вне этого интервала ветвь через неподвижную точку нарушает хотя бы одно граничное требование.
Поэтому по контракту проекта она не является сильным нечётким отрицанием.

## Следствия {#consequences}

- Полный перебор с шагом `epsilon` математически не нужен; он удалён задачей #57.
- Задача #57 реализует приведённую устойчивую замкнутую формулу без цикла сканирования.
- Параболическое семейство требует `alpha in [1/4, 3/4]`; это отличается от области
  `0 < alpha < 1` отдельного кусочно-линейного семейства `FuzzyNOT`.
- Задача #58 проверяет концы интервала, неподвижную точку, монотонное убывание,
  инволютивность и обе недопустимые области параметра.
