# Контракты формул и параметров функций принадлежности {#membership-function-formula-and-parameter-contracts}

- Статус: справочный контракт задачи #50
- Связанный ADR: [ADR-0003](../../../../adr/0003-membership-function-contracts.md)
- Связанный исполняемый интерфейс: `fuzzyroutines.FuzzyRoutines.MFunction`

## Назначение {#purpose}

Таблица фиксирует математику, доступную через исторические идентификаторы фабрики,
и различает защищённый исторический идентификатор и стандартное математическое название.
Она не переопределяет существующее соглашение о параметрах неявно.

Функция принадлежности отображает вход в степень из `[0, 1]` согласно формулировке
нечёткого множества, введённой [Заде (1965)](https://doi.org/10.1016/S0019-9958(65)90241-X).
Задача #51 обеспечивает точные наборы параметров, конечные вещественные значения
и приведённые ниже геометрические ограничения при создании объекта и через публичный сеттер параметров.

| -------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `hyperbolic`               | Рационально-степенное убывающее правое плечо; не стандартное название гиперболы        | `1` при `x <= c`; иначе `1 / (1 + (a * (x - c)) ** b)`. `c` — левый порог, `a` — масштаб, `b` — показатель степени.                                           | Конечные `x, a, b, c`; `a > 0`, `b > 0`.                                                                   | Сохранить `hyperbolic`; не добавлять ложный псевдоним стандартного названия.                      |
| `bell`                     | Кусочно-квадратичный колокол с плоской вершиной; не обобщённый колокол Джанга (1993)   | Возрастающее квадратичное плечо от `a` до `b`, плато от `b` до `c`, затем зеркальное убывающее плечо до `c + b - a`.                                          | Конечные `a, b, c`; `a < b <= c`.                                                                          | Сохранить `bell`; без псевдонима `generalizedBell`.                                               |
| `parabolic`                | Квадратичное возрастающее S-образное плечо                                             | Пусть `t = (x - a) / (b - a)`. Значение `0` при `x <= a`, `2t**2` при `0 < t <= 1/2`, `1 - 2(1 - t)**2` при `1/2 < t < 1` и `1` при `x >= b`.                 | Конечные `a, b`; `a < b`.                                                                                  | `sShoulder` — точный дополнительный псевдоним той же реализации и параметров.                     |
| `triangle`                 | Треугольная функция принадлежности с историческим порядком параметров                  | `a` — левая опорная точка, **`c` — вершина**, `b` — правая опорная точка. Геометрический порядок `a < c <= b` отличается от исторического порядка аргументов. | Конечные `a, b, c`; `a < c <= b`. Граница `c = b` сохраняет исторический верхний терм по умолчанию.        | Сохранить `triangle(a, b, c)`; псевдоним с обычным порядком должен иметь отдельное явное имя.     |
| `trapezium`                | Трапециевидная функция принадлежности с историческим порядком параметров               | `a` — левая опорная точка, `c` — начало плато, `d` — конец плато, `b` — правая опорная точка. Геометрический порядок `a < c <= d < b`.                        | Конечные `a, b, c, d`; `a < c <= d < b`.                                                                   | Сохранить `trapezium(a, b, c, d)`; псевдоним с обычным порядком должен иметь отдельное явное имя. |
| `exponential`              | Гауссова функция принадлежности                                                        | `exp(-0.5 * ((x - a) / b)**2)`. `a` — центр, `b` — масштаб.                                                                                                   | Конечные `x, a, b`; канонический масштаб `b > 0`. Историческая формула не зависит от знака ненулевого `b`. | `gaussian` — точный дополнительный псевдоним той же реализации и параметров.                      |
| `sigmoidal`                | Логистическая сигмоида                                                                 | `1 / (1 + exp(-a * (x - b)))`. `a` — параметр наклона, `b` — средняя точка. ## Названия в источниках {#reference-naming}

Стандартный параметризованный обобщённый колокол имеет три параметра: ширину, наклон и центр.
Его формула отличается от исторической квадратичной реализации `bell` с плоской вершиной.
Исходная статья Джанга об ANFIS определяет трёхпараметрический обобщённый колокол
и роли центра, полуширины и наклона: [Jang (1993)](https://doi.org/10.1109/21.256541).
Историческая формула `exponential` имеет точно гауссову форму, а `parabolic`
является возрастающим квадратичным плечом, а не гауссовой функцией.

## Переходные имена реестра совместимости {#transitional-compatibility-registry-names}

Современные по смыслу имена, доступные через историческую фабрику `MFunction`,
являются дополнительными ключами реестра, а не отдельными формулами:

| Имя в реестре            | Исторический идентификатор | Промежуточный контракт параметров |
| ------------------------ | -------------------------- | --------------------------------- |
| `sShoulder`              | `parabolic`                | те же `a, b`                      |
| `gaussian`               | `exponential`              | те же `a, b`                      |
| `logistic`               | `sigmoidal`                | те же `a, b`                      |
| `harringtonDesirability` | `desirability`             | без параметров                    |

Каждый псевдоним разрешается в тот же связанный метод, что и исторический идентификатор:
проверка и вычисление используют одну реализацию. Это не делает исторический метод каноническим.
Специализированный современный модуль содержит реализации формул и обычные контракты параметров;
исторические идентификаторы фабрики являются псевдонимами или явными адаптерами совместимости.

Для `bell`, `triangle` и `trapezium` псевдонимы не добавляются: их историческая форма
или порядок параметров сделали бы обычное имя неоднозначным без отдельного современного контракта API.

Преобразование желательности приписывается E. C. Harrington, *The Desirability Function*,
*Industrial Quality Control* 21(10), 494–498 (1965). Это происхождение документировано
в рецензируемом журнале *Metrika*: [Trautmann and Weihs (2006)](https://doi.org/10.1007/s00184-005-0012-0).

## Правило совместимости {#compatibility-rule}

Исторические идентификаторы фабрики, имена ключевых аргументов и порядок параметров
остаются частью публичного интерфейса совместимости. Недопустимая конфигурация отклоняется
при создании функции принадлежности или переназначении всей таблицы параметров,
а не превращается в правдоподобную нулевую степень принадлежности.
