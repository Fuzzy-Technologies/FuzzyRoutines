# Указатель API {#api-index}

FuzzyRoutines предоставляет два намеренно различных интерфейса:

- [Современный API](modern/index.md) содержит неизменяемые модели предметной области и явные политики для нового кода.
- [Исторический API](legacy/index.md) сохраняет наблюдаемое поведение фасада 1.0.3 ради совместимости.

Поиск поможет найти модуль, класс, функцию, метод или свойство. В описании каждого объекта API приведены его сигнатура и ссылка на исходный код.

[Указатель публичных примеров](../guides/example-index.md) связывает каждый поддерживаемый символ с выполненным блоком руководства. Общую модель объясняют [схемы вычислений](../guides/workflow.md), возвращаемые сведения — [записи результатов](../guides/results.md), сопровождение существующих потребителей — [исторические рецепты](../guides/historical-recipes.md).
