# Пакетные вычисления {#optional-batches}

[Практический пример](../../guides/numpy-batches.md) объясняет установку, форму
массивов, владение памятью и обработку отсутствия совпадений. Импортируйте API
из `fuzzyroutines.batches`; скалярным вызовам NumPy не требуется.

::: fuzzyroutines.batches
    options:
      members:
        - EvaluateMembershipBatch
        - FuzzifyBatch
        - ScaleBatchResult
