# Построение ограниченной лингвистической шкалы

Когда соседние термы должны перекрываться, используйте
`fuzzyroutines.scale_builders.BuildLinearScale(terms, lower, upper)`.
Передайте упорядоченные пары «метка, координата вершины» и конечные
границы замкнутого универсального множества. Между соседними вершинами
степень принадлежности одного терма линейно убывает, а другого линейно
возрастает. У крайних термов степень равна единице от вершины до
соответствующей границы множества. Вершина может совпадать с границей.
Если терм один, его степень равна единице на всём множестве.

Когда каждой координате должен соответствовать ровно один интервал,
используйте
`fuzzyroutines.scale_builders.BuildIntervalScale(labels, boundaries)`.
Границ должно быть на одну больше, чем меток. Внутренняя граница
принадлежит интервалу справа, а верхняя граница входит в последний интервал.

Обе функции возвращают `LinguisticScale` и сохраняют порядок меток.
Координаты вершин и границ должны быть конечными и строго возрастать.
Метки не могут быть пустыми или состоять только из пробелов. Они должны
быть уникальными при сравнении без учёта регистра по правилам Unicode.
При фаззификации координаты вне универсального множества возникает
обычная ошибка области определения.

При вершинах 0, 2 и 7 степени для координаты 3 в порядке термов составляют
`(0, 4/5, 1/5)`. Для интервалов с границами −2, 0, 2 и 9 получаем
`(0, 0, 1)`. В универсальном множестве сумма степеней равна единице.
Линейная интерполяция использует точные отношения для целых, рациональных
и двоичных 64-битных значений. Для других вещественных скалярных типов
используется их представление в binary64.
