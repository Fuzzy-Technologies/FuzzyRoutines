# Современный API {#modern-api}

Корневой пакет [`fuzzyroutines`][fuzzyroutines] повторно экспортирует рекомендуемые публичные символы. Страницы модулей сохраняют архитектурное владение ими и предоставляют стабильные ссылки с полными квалифицированными именами:

| Модуль                                  | Назначение                                                                      |
| --------------------------------------- | ------------------------------------------------------------------------------- |
| [`alphacuts`](alphacuts.md)             | Точные дискретные и выборочные непрерывные альфа-срезы                          |
| [`defuzzification`](defuzzification.md) | Аналитическое и адаптивное вычисление непрерывного центроида                    |
| [`domain`](domain.md)                   | Объявленные универсальные множества и конечные области интегрирования           |
| [`exceptions`](exceptions.md)           | Современные категории ошибок параметров, областей и численных операций          |
| [`fuzzysets`](fuzzysets.md)             | Скалярные нечёткие множества, операторы, политики и нормализация                |
| [`linguistic`](linguistic.md)           | Неизменяемые лингвистические термы и упорядоченные шкалы                        |
| [`membership`](membership.md)           | Неизменяемые аналитические функции принадлежности с геометрическими параметрами |
| [`operators`](operators.md)             | Скалярные политики отрицания и норм                                             |
| [`properties`](properties.md)           | Точные или выборочные поддержка, ядро, граница и высота                         |
| [`relations`](relations.md)             | Сравнения равенства и включения с явной областью                                |

Канонический набор импортов из корня приведён в [экспортах пакета](package.md).
