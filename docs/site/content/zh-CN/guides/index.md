# 完整应用场景 {#worked-scenarios}

从[安装和温度快速示例](../quick-start.md)开始，再选择与应用最接近的问题：

1. [温度舒适度](temperature.md)：定义物理论域，读取每个隶属度。
2. [严重程度标签与拒绝分类](risk.md)：拒绝依据过弱的分类结果。
3. [两个传感器判据](sensors.md)：组合不同测量值的隶属度。
4. [维护预警区域](alarm.md)：组合相同论域上的模糊集。
5. [质量 α-截集](alpha-cuts.md)：区分精确离散结果与采样结果。
6. [质心与数值精度](centroid.md)：独立验证面积矩。
7. [尺度审查](scale-audit.md)：发现并列最大值、覆盖空缺和偏离单位分解的情况。
8. [自定义质量模型](custom.md)：使用带类型的可调用对象，并归一化离散数据。
9. [历史通用模糊尺度](universal-fuzzy-scale.md)：使用现代 API 重建 Universal Fuzzy Scale，比较隶属曲线与分类结果。

每个场景都定义单位或评分范围，展示中间值，并断言预期结果。参数是示意性的专家选择。这些例子演示模糊计算，并不构成经过验证的控制器、训练后的统计模型或完整的规则推理引擎。

## 一致地理解数学含义 {#read-the-mathematics-consistently}

对于模糊集 $A$，隶属函数将坐标映射为隶属度：

$$
\mu_A: U \longrightarrow [0,1].
$$


**论域** $U$ 声明允许的坐标。**模糊集的支集**由隶属度严格大于零的坐标组成，可能远小于论域；其闭包包含极限点。**模糊集的核**由隶属度等于一的点组成。这些概念都不表示概率分布。

对于两个隶属度 $a,b$，T-范数表示合取，S-范数表示析取。最小值／最大值策略与代数策略具有不同的数值含义，应有意识地选择，并与模型一同记录。

弱 α-截集包含隶属度等于阈值的点。精确离散运算检查每个声明的坐标。连续采样报告指定网格上的观测，不能证明网格点之间的行为。

连续质心是在显式有限积分域上两个面积矩之比。解析公式与自适应积分具有不同的结果依据和失败条件。质心是代表性坐标；只有另行建立了能够支持该解释的概率模型，才可将其理解为概率分布的期望值。

可通过[计算路径](workflow.md)选择分类或质心积分。还可以比较[运算策略](operators.md)，检查和重建[结果记录](results.md)，学习[错误处理](errors.md)，或维护[历史接口集成](historical-recipes.md)。[公共 API 示例索引](example-index.md)将每个已登记符号链接到实际执行的用法。在窄屏设备上，可打开 SVG 链接查看完整图形。
