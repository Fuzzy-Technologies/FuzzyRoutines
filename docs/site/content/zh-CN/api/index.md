# API 索引 {#api-index}

FuzzyRoutines 提供两个有意区分的接口：

- [现代 API](modern/index.md)为新代码提供不可变领域模型和显式策略。
- [历史 API](legacy/index.md)保留已观察到的 1.0.3 兼容接口行为。

使用搜索查找模块、类、函数、方法和属性。每个 API 条目都包含签名和源代码链接。

[公共示例索引](../guides/example-index.md)将每个支持的符号映射到已执行的指南代码块。整体模型见[计算路径](../guides/workflow.md)，返回的证据见[结果记录](../guides/results.md)，现有调用方用法见[历史接口示例](../guides/historical-recipes.md)。
