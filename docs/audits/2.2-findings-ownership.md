## Evidence boundaries

- **Selective coverage.** The [full mathematical CI workflow] measures
  production-package line and branch coverage with the executable example module
  excluded and compares actual sequential and process results. The same workflow
  uses selected tests or import checks on routine updates. The
  [mathematical coverage review](2026-10-09-math-coverage-review.md) documents
  inspected cases and residual gaps. Task [#432] owns integrated installed
  acceptance for the selected 2.2 scope.
- **Custom callback trust.** An active custom evaluator must be distinguished
  from a library-owned evaluator before using analytical evidence ([#284]).
  Caller-owned callbacks must remain consistent during an operation. Sampled
  observations cannot certify an arbitrary unsampled feature or prove a global
  error bound. Portable configuration uses a closed allowlist and excludes
  executable callbacks ([#384], [#385], [#386]). Sampled diagnostics retain their
  evidence limits ([#409]).
- **Neural prototype.** [ADR-0019] covers a standalone optional CPU example
  with fixed fuzzy encodings and disjoint data splits. It provides measured
  evidence on its own task and environment. [ADR-0020] and [#428] govern
  trainable Sugeno research. Interval type-2, uncertainty and adaptive work
  remain research ([#429], [#430], [#431]). A supported production API needs
  a separate scope decision.
- **Compatibility.** [ADR-0001] and [ADR-0016] protect established 2.x and
  historical-scale behavior. The Min/Low/Med/High/Max coefficients, term
  order, per-term centroid windows and last-exact-maximum policy remain
  separate from presentation, sampling and model fitting.
