Quick start

How well does a room temperature of 24 °C fit the idea of “comfortable”? Define full comfort at 22 °C, decreasing to zero at 16 and 28 °C, then evaluate the measurement.

1 · Install

Use Python 3.13 or 3.14 in your project environment.

This example uses the 2.0 API. Install the matching version from PyPI; historical 1.x releases do not provide this API.

Terminal
python -m pip install fuzzyroutines==2.0.0

2 · Run the example

Save this as comfort.py and run python comfort.py.

Python · comfort.py
from fuzzyroutines import (
    ContinuousUniverse, ScalarFuzzySet, Triangle,
)

universe = ContinuousUniverse(
    0, 40, leftClosed=True, rightClosed=True,
)
comfort = ScalarFuzzySet(universe, Triangle(16, 22, 28))
temperature = 24
grade = comfort.Membership(temperature)

print(f"Temperature: {temperature} °C")
print(f"Comfort membership: {grade:.3f}")

3 · Read the result

Expected output
Temperature: 24 °C
Comfort membership: 0.667

The temperature is on the descending side of the triangle: (28 − 24) / (28 − 22) = 2/3. A grade of 0.667 describes partial membership in the comfort set, not a probability.

These thresholds are illustrative model choices. Add other terms to distinguish comfortable, warm and hot conditions in your application.

Scope and compatibility

Implemented in 2.0: the modern scalar API and historical compatibility facade, with explicit validation and documented numerical corrections.

Future work: additional defuzzification methods, executable convexity queries, symmetric difference and production vectorized execution. These are outside the current scalar API.
