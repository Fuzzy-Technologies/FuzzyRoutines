Focused scope

A fuzzy-mathematics layer, not another notebook system.

Python and notebook environments remain the hosts. FuzzyRoutines supplies reusable fuzzy primitives that can be embedded in research, expert systems, decision models, and production software.

v2 engineering targets

Correct first. Fast by evidence. Parallel by design.

Target

Mathematical reliability

Authoritative formulas, reference cases, valid domains, boundary tests, and compatibility decisions that are visible instead of implicit.

Target

Measured performance

Low-overhead scalar paths and efficient batches. Optimizations ship with parity, timing, and memory evidence—never with superlatives alone.

Target

Process-safe concurrency

Deterministic, reentrant models without hidden global mutable state, suitable for independent CPU workers and supported Python interpreters.

Current status

Active correctness-focused modernization

The focused typed modules are the default modern API as that surface is completed. The historical public API remains available as a compatibility facade while documented defects are repaired in reviewable steps. Vectorized backends, free-threaded execution, and scaling claims remain future work until their dedicated parity and benchmark gates pass.

Run it locally

Small API, inspectable behavior.

Install the active development branch, then create and evaluate a fuzzy set.

python -m pip install \
  git+https://github.com/Fuzzy-Technologies/FuzzyRoutines.git@develop
from fuzzyroutines.FuzzyRoutines import FuzzySet, MFunction, TNorm

membershipFunction = MFunction(
    "triangle", a=0.0, b=1.0, c=0.5
)
fuzzySet = FuzzySet(
    membershipFunction,
    supportSet=(0.0, 1.0),
    linguisticName="Medium",
)

print(TNorm(0.4, 0.7, normType="algebraic"))
print(fuzzySet.Defuz())
