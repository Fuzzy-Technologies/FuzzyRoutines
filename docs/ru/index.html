Быстрый старт

Насколько температура в комнате 24 °C соответствует понятию «комфортно»? Зададим полное соответствие при 22 °C и его убывание до нуля при 16 и 28 °C, затем вычислим степень принадлежности для измеренной температуры.

1 · Установка

Используйте Python 3.13 или 3.14 в окружении проекта.

Пример использует опубликованную версию 2.0.0. Установите эту стабильную версию из PyPI: в исторических релизах 1.x этого API нет.

Терминал
python -m pip install fuzzyroutines==2.0.0

2 · Запуск примера

Сохраните код в comfort.py и выполните python comfort.py.

Python · comfort.py
from fuzzyroutines import (
    ContinuousUniverse, ScalarFuzzySet, Triangle,
)

universe = ContinuousUniverse(
    0, 40, leftClosed=True, rightClosed=True,
)
comfort = ScalarFuzzySet(universe, Triangle(16, 22, 28))
temperature = 24
grade = comfort.Membership(temperature)

print(f"Temperature: {temperature} °C")
print(f"Comfort membership: {grade:.3f}")

3 · Разбор результата

Ожидаемый вывод
Temperature: 24 °C
Comfort membership: 0.667

Температура находится на нисходящей стороне треугольника: (28 − 24) / (28 − 22) = 2/3. Значение 0.667 — это степень принадлежности нечёткому множеству комфортных температур, а не вероятность.

Эти пороги выбраны для примера. Добавьте другие термы, чтобы различать комфортные, тёплые и жаркие условия в своей задаче.

Воссоздайте историческую шкалу с исходными коэффициентами и сравните её с современной реализацией. В руководстве приведены кривые принадлежности, граничные случаи и правила выбора уровня.

Используйте лингвистические уровни для интерпретации нормализованных оценок риска, выявленных проблем безопасности или эффективности защитных мер. Определите, что означает рост оценки в вашей модели: степень принадлежности не является вероятностью инцидента.
