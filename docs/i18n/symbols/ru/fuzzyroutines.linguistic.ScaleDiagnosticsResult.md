Неизменяемые выборочные сведения о покрытии, перекрытиях, пробелах и разбиении.

Результат описывает только объявленную конечную сетку и не доказывает непрерывное свойство между её координатами.

Attributes:
    analysisDomain: Конечный замкнутый интервал диагностической выборки.
    policy: Размер сетки и политика допусков диагностики.
    points: Упорядоченные сведения для каждой равноотстоящей координаты сетки.
