Современный публичный API с явными контрактами универсальных множеств и свойств нечётких множеств.

Литерал `__all__` определяет отобранный современный API: неизменяемые фабрики функций принадлежности,
контракты типов, универсальные множества, нечёткие множества и политики. Исторические изменяемые
объекты доступны только через `fuzzyroutines.FuzzyRoutines`; импорт пакета не выполняет
вычислений, ввода-вывода или изменений конфигурации.
