Экспортирует переносимый проект без чтения файлов и вычислений по сценариям.

Args:
    project: Проверенный снимок, полученный при загрузке проекта формата v1.
    formatName: Явно выбранный формат вывода. По умолчанию используется JSON.

Returns:
    Проверенные байты UTF-8 с завершающим переводом строки. При одинаковом входе вывод совпадает побайтно.

Raises:
    ConfigurationError: Снимок нельзя представить в виде корректного проекта формата v1.
    ImportError: Не установлена необходимая дополнительная зависимость для конфигураций или YAML.
    ValueError: Выбранный формат не поддерживается.
