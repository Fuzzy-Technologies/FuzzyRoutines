Явно выбираемые пакетные вычисления встроенных функций принадлежности и шкал с NumPy.

Импорт модуля не загружает NumPy. Только вызов пакетного API выбирает вычисления над массивами float64; скалярные вызовы не переключаются на этот путь. Аналитические определения и проверка параметров берутся из скалярного ядра. Область применимости определяет ADR-0018.
