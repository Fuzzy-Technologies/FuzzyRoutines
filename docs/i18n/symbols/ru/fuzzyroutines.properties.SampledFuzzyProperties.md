Приближённые наблюдения конечных координат на непрерывной области.

`SampleProperties` создаёт равномерную сетку и по степеням принадлежности определяет точки каждой записанной области. При прямом создании объекта проверяются структура таблицы, охват границ, принадлежность точек записанных областей исходной сетке и высота. Равномерность шага не проверяется, а три записанные области не вычисляются заново.

Attributes:
    analysisDomain: Замкнутый интервал, покрываемый сеткой.
    sampleCount: Число координат, включая обе границы.
    coordinates: Строго возрастающие координаты, охватывающие `analysisDomain`.
    grades: Проверенные степени для `coordinates`.
    positiveSupportSamples: Записанное подмножество координат выборки; `SampleProperties` выбирает степени больше нуля.
    coreSamples: Записанное подмножество координат выборки; `SampleProperties` выбирает степени, равные единице.
    boundarySamples: Записанное подмножество координат выборки; `SampleProperties` выбирает степени строго между нулём и единицей.
    heightEstimate: Наибольшая наблюдаемая степень, а не доказательство точной верхней грани.
    method: Непустая метка происхождения выборки. `SampleProperties` использует `"uniform-grid"`.
