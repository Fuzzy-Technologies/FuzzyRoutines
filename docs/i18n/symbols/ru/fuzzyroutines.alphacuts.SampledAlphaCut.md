Конечные наблюдения непрерывного альфа-среза с полным описанием происхождения.

Attributes:
    alpha: Слабый порог принадлежности в $[0, 1]$.
    analysisDomain: Замкнутый интервал, покрываемый сеткой.
    sampleCount: Число координат сетки, включая обе границы.
    coordinates: Строго возрастающие координаты, охватывающие `analysisDomain`. `SampleAlphaCut` создаёт равномерную сетку; прямое создание записи не проверяет равенство шагов повторно.
    grades: Проверенные степени принадлежности для `coordinates`.
    cutSamples: Координаты, степени которых удовлетворяют $\mathrm{grade} \geq \alpha$.
    method: Обязательная метка происхождения, сейчас всегда `"uniform-grid"`. Она указывает поддерживаемый контракт производителя, но сама по себе не доказывает равномерность напрямую созданной записи.
