Возвращает среднее представителей активных термов, взвешенное по принадлежности.

Для степени $g_i$ и центроида терма $c_i$ результат равен $\sum_i g_i c_i / \sum_i g_i$. Это не центроид обрезанного, масштабированного или иначе агрегированного нечёткого множества. Для такого центроида нужны явная агрегация и собственная область интегрирования.

Args:
    grades: Явный кортеж длины N в порядке `termNames`; каждая конечная действительная степень лежит в `[0, 1]`. Сумма не обязана равняться единице.

Returns:
    Конечного численного представителя в координатах шкалы. Рациональные и binary64-степени, а также вычисленные центроиды суммируются как точные дроби с единственным преобразованием конечного отношения в binary64. Для остальных действительных скаляров используется их представление binary64. Определённый центроид требуется только для термов с положительной степенью; термы с нулевой степенью вносят нулевой вклад.

Raises:
    TypeError: Вектор не является кортежем или содержит недействительную степень.
    InvalidParameterError: Неверна длина вектора или степень принадлежности.
    UndefinedResultError: Все степени нулевые, активный терм имеет нулевую площадь либо среднее нельзя представить конечным числом.
    CentroidConvergenceError: Вычисление центроида активного терма превысило ограничение.
