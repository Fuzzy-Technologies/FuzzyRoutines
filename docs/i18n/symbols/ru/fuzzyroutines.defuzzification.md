Детерминированная дефаззификация методом центроида для непрерывных скалярных нечётких множеств.

Для поддерживаемых полиномиальных и гауссовых семейств используются аналитические моменты.
Для других непрерывных вызываемых объектов применяется адаптивная квадратура Симпсона с явно
заданными настройками. Импорт модуля не выполняет вычислений или ввода-вывода.
