Входные координаты и настройка трассировки для сценария, по которому ещё не выполнены вычисления.

Attributes:
    modelId: Точный идентификатор модели в проекте.
    inputs: Конечные координаты по идентификаторам входов модели в формате обмена.
    trace: Запрашивает ли сценарий трассировку при явном запуске вычислений.
