Неизменяемая конфигурация непрерывной шкалы и её численных представителей.

Каждая операция обрабатывает одно наблюдение. Векторы принадлежностей — явные кортежи длины `len(scale.terms)` в порядке объявления термов, без дополнительной оси для нескольких наблюдений. Входы и прогнозы уже должны использовать координаты шкалы; перевод единиц измерения и предобработку с параметрами, определяемыми по обучающей выборке, выполняет приложение. Методы не обрезают входы, не подбирают параметры по данным и не заменяют неизвестный уровень нулём. Центроиды служат представителями входных или целевых значений при обучении; они не являются обучаемыми весами.

Attributes:
    scale: Упорядоченные непрерывные термы, универсальные множества которых содержат все вычисляемые координаты.
    integrationDomains: По одному явному интервалу вычисления центроида для каждого терма, в порядке шкалы и внутри универсального множества терма.
    selectionPolicy: Явная политика равных максимумов и отсутствия совпадения для прогнозов.
    centroidPolicy: Необязательные ограничения численного интегрирования; `None` использует параметры скалярного центроида по умолчанию.

Notes:
    Выбор уровня и кодирование центроидом теряют информацию. Фаззификация и дефаззификация в общем случае не являются обратными преобразованиями. Пользовательские функции принадлежности хранятся по ссылке и могут иметь изменяемое состояние; неизменяемость конфигурации не делает такие функции чистыми.
