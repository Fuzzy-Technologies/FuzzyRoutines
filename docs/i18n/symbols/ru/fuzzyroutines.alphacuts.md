Точные дискретные альфа-срезы и явно выборочные альфа-срезы непрерывных множеств.

Для альфа-среза используется нестрогое условие $\mu(x) \geq \alpha$.
Для `DiscreteUniverse` вычисление точно, поскольку проверяется каждый объявленный координатный элемент.
Для произвольного вызываемого объекта на непрерывном универсальном множестве конечное число проверок
не позволяет получить точное решение. Поэтому непрерывное вычисление возвращает отдельный результат
выборки с информацией о способе получения и не заявляет точной геометрии.
