Прогнозы, статусы и метаданные в порядке объявления модели, доступные только для чтения.

Каждое значение, статус и признак допустимости относятся к одной строке исходных данных. У допустимой строки статус равен нулю, а значение конечно. У ошибочной строки значение равно NaN, а статус отличен от нуля. При отключённой трассировке её данные отсутствуют.
