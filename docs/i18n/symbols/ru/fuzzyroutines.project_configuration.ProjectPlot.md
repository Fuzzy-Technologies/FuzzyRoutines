Настройки отображения для одной именованной модели и её шкалы.

Attributes:
    modelId: Точный идентификатор модели в проекте.
    scaleId: Точный идентификатор шкалы в выбранной модели.
    title: Необязательный заголовок графика.
    xLabel: Необязательная подпись горизонтальной оси.
    termColors: Переопределения цветов без прозрачности по точным идентификаторам термов.
