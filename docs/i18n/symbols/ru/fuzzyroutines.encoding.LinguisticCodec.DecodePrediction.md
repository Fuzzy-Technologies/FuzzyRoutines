Интерпретирует один численный прогноз с полными сведениями о принадлежности.

Args:
    prediction: Конечный скаляр в координатах шкалы, принадлежащий универсальному множеству каждого терма.

Returns:
    Упорядоченные степени, максимальную принадлежность, равные максимумы и выбранные термы согласно политике. При отсутствии совпадения кортеж `selectedTerms` пуст.

Raises:
    TypeError: Прогноз не является действительным скаляром.
    ValueError: Прогноз неконечен или лежит вне любого из универсальных множеств.
