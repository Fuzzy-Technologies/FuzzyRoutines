Предоставляет исторические имена нечёткой логики через явные адаптеры совместимости.

Канонические формулы функций принадлежности, операторы, области и численные политики находятся
в специализированных современных модулях. Приватные адаптеры сохраняют исторический порядок
аргументов, изменяемое состояние, шкалы по умолчанию и идентичность возвращаемых объектов.
В новом коде следует импортировать специализированные модули или современный API пакета.

Литерал `__all__` сохраняет пятнадцать поддерживаемых исторических символов.
Импортируемые вспомогательные объекты и приватные адаптеры не входят в этот контракт совместимости.
