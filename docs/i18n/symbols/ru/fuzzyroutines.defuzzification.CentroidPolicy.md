Неизменяемые ограничения ошибки и объёма работы при адаптивном интегрировании центроида.

Attributes:
    absoluteTolerance: Целевой абсолютный допуск для площади принадлежности.
    relativeTolerance: Целевой относительный допуск для обоих вычисляемых моментов.
    maximumDepth: Максимальная глубина рекурсивного деления одного интервала пополам.

Notes:
    Абсолютный допуск первого момента равен `absoluteTolerance`, умноженному на наибольший модуль координаты области интегрирования. Полиномиальные аналитические пути не выполняют итераций. Гауссовы моменты используют `relativeTolerance`, чтобы отклонить недостаточно разрешённое вычитание в замкнутой формуле до передачи адаптивному интегрированию с той же политикой.
