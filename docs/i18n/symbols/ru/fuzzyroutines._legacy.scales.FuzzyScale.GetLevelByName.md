Ищет уровень по полному имени с учётом регистра или без него.

Args:
    levelName: Искомое имя.
    exactMatching: При `True` учитывает регистр; иначе сравнивает формы в верхнем регистре.

Returns:
    Словарь найденного уровня или `None`, если совпадения нет.

Notes:
    Регистронезависимый поиск использует историческую таблицу имён в верхнем регистре.
    Ни один режим не выполняет поиск по подстроке, префиксу или приблизительному совпадению.
