Возвращает кусочно-линейный треугольник с обычным порядком left, peak, right.

Конечные вещественные параметры должны удовлетворять `left < peak <= right`; логические значения отклоняются. Возвращаемая функция неизменяема и соблюдает граничные соглашения семейства, описанные в `MembershipFunction`.

Args:
    left: Левая опорная точка с нулевой принадлежностью.
    peak: Координата единичной принадлежности, возможно равная `right`.
    right: Правая граница формы.

Returns:
    Проверенная неизменяемая аналитическая функция принадлежности.

Raises:
    ValueError: Параметры невещественные, неконечные или нарушают контракт семейства.
