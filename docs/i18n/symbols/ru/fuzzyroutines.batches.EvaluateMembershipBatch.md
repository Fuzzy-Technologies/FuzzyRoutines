Вычисляет встроенную функцию принадлежности для массива, создавая новый результат float64.

Args:
    function: Встроенное семейство без переопределённого вычислителя; параметры int/float должны точно представляться в float64.
    values: Числовой массив или прямоугольная последовательность ранга не ниже одного. Пустые массивы и срезы допустимы. Координаты копируются в float64; логические, комплексные, объектные, строковые и нефинитные значения отклоняются.
    backend: Явно выбранный backend; поддерживается только `"numpy"`.

Returns:
    Новый доступный для записи массив float64 исходной формы. Вход не изменяется и не сохраняется по ссылке. Степени принадлежности не нормализуются.

Raises:
    ImportError: NumPy не установлен; сообщение содержит команду установки дополнения.
    TypeError: Неподдерживаемый тип входа, вычислитель или представление параметров.
    ValueError: Неверный backend, координаты или вычисленные степени принадлежности.
    OverflowError: Переполнение или недопустимый промежуточный результат активной ветви.
    ZeroDivisionError: Квадрат ширины активной квадратичной ветви округлился до нуля.

Notes:
    Сравнение со скалярным вычислением проводится на координатах после преобразования в float64, с абсолютным допуском 1e-12 и нулевым относительным допуском. При ошибке частичный результат не возвращается; автоматического перехода к скалярному циклу нет.
