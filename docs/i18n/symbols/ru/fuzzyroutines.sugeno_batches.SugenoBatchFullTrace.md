Данные о правилах и входах в порядке объявления модели, доступные только для чтения.

Для ошибочных строк степени принадлежности, силы срабатывания, значения консеквентов и вклады равны NaN. Маска точного отношения равна false в ошибочных строках. В успешных строках она отмечает нормировки, рассчитанные с использованием точного отношения. Веса правил хранятся в одном векторе.
