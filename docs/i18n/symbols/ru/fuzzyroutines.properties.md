Контракты производных множества поддержки, ядра, границы и высоты скалярных нечётких множеств.

Непрерывные аналитические результаты получаются из объявленной геометрии семейства функций
принадлежности, а не сканированием значений с плавающей точкой. Дискретные универсальные множества
вычисляются точно во всех объявленных координатах. Для непрерывной выборки возвращается отдельный
тип результата, фиксирующий численный способ получения и не допускающий смешения с точным
математическим множеством поддержки.
