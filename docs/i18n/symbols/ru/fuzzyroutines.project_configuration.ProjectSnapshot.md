Снимок для чтения, содержащий именованные модели и настройки загруженного проекта.

Attributes:
    models: Самостоятельные конфигурации по точным идентификаторам моделей проекта.
    defaults: Явно заданный выбор, если он указан в исходном документе.
    units: Подписи для отображения, сгруппированные по идентификатору модели и затем по локальному идентификатору универсума.
    plots: Настройки отображения по идентификаторам графиков.
    evaluations: Сценарии без выполненных вычислений по идентификаторам сценариев.
