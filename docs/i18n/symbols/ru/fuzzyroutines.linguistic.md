Типизированные неизменяемые лингвистические термы, поиск по шкале и фаззификация.

Поиск по имени либо учитывает регистр, либо использует регистронезависимое сравнение Unicode.
Современная фаззификация записывает все степени принадлежности и применяет явные политики
разрешения равенств и минимальной уверенности, не меняя исторический API совместимости.
