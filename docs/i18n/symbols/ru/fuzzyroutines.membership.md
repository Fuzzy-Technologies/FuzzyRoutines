Неизменяемые скалярные функции принадлежности с явными геометрическими параметрами.

Аналитические семейства содержат собственные скалярные формулы. Исторические адаптеры преобразуют
старый порядок параметров в контракт этого ядра; импорт модуля не импортирует изменяемый API
совместимости. Вычисления с плавающей точкой сохраняют установленные арифметические правила
и поведение на границах, включая потерю представимости положительных хвостов с округлением к нулю.
