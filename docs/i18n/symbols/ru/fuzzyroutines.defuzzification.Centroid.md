Возвращает непрерывный центр площади на явной конечной области.

Результат равен $\int x\mu(x)\;\mathrm{d}x / \int \mu(x)\;\mathrm{d}x$. Кусочно-полиномиальные и гауссовы источники `MFunction` используют аналитические моменты, когда замкнутая формула устойчива; остальные вызываемые функции используют адаптивную квадратуру Симпсона.

Args:
    fuzzySet: Непрерывное скалярное нечёткое множество, вычисляемое без сохранённого состояния.
    integrationDomain: Конечный замкнутый интервал внутри универсального множества.
    policy: Неизменяемая конфигурация допусков и объёма адаптивной работы. `None` выбирает [CentroidPolicy][fuzzyroutines.defuzzification.CentroidPolicy].

Returns:
    Конечная координата центроида внутри `integrationDomain`.

Raises:
    InvalidParameterTypeError: Множество, универсальное множество, область или политика имеют неверный тип.
    InvalidDomainError: Область выходит за пределы универсального множества.
    UndefinedResultError: Площадь принадлежности нулевая либо вычисленный момент или центроид неконечен.
    CentroidConvergenceError: Адаптивная квадратура превышает `maximumDepth`.

Notes:
    Предполагается достаточная регулярность произвольной функции для адаптивной квадратуры. Функция с неразрешёнными особенностями между всеми проверяемыми координатами требует аналитического семейства или отдельно утверждённого API разбиения области; фиксированная запасная сетка не используется.
