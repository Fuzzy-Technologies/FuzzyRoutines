Неизменяемые скалярные функции принадлежности по заданным точкам с явными правилами вычисления.

Дискретные таблицы хранят значения для точного поиска. Кусочно-линейные функции
задают степени между узлами и определяют поведение за пределами интервала
узлов. Ни одно из представлений не требует дополнительных зависимостей.
