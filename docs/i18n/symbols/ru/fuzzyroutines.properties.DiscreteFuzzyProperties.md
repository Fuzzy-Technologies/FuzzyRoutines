Точные производные свойства на явно дискретном универсальном множестве.

Attributes:
    universe: Полностью перебранное дискретное универсальное множество.
    positiveSupport: Объявленные точки с положительной принадлежностью.
    supportClosure: Совпадает с `positiveSupport` в дискретной топологии.
    core: Объявленные точки с принадлежностью один.
    boundary: Объявленные точки с принадлежностью строго между нулём и единицей.
    height: Максимальная принадлежность среди всех объявленных точек.
