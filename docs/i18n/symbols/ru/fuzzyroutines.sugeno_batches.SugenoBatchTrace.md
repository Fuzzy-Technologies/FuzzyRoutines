Число сработавших правил и максимальная сила срабатывания, доступные только для чтения. Полная трассировка правил предоставляется по запросу.

Если ни одно правило не сработало, оба значения равны нулю. При других ошибках число равно -1, а максимум — NaN. Полные данные доступны только в режиме полной трассировки.
