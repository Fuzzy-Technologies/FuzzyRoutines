Классифицирует массив по шкале из встроенных семейств с явной скалярной политикой.

Args:
    scale: Современная шкала из допустимых встроенных функций. Границы непрерывных и точки дискретных универсальных множеств должны точно представляться в float64.
    values: Координаты пакетного API, принадлежащие универсальному множеству каждого терма. Нарушение отклоняет весь пакет.
    policy: Политика first/last/all. По умолчанию выбирается первый точный максимум, нулевое покрытие даёт отсутствие совпадения. Пороги должны иметь тип int/float; пороги произвольной рациональной точности поддерживаются только скалярным API.
    backend: Явный выбор способа вычислений; поддерживается `"numpy"`.

Returns:
    Упорядоченные степени принадлежности, их максимум (`confidence`), маски равных максимумов и выбранных термов. Массивы независимы и защищены от записи. Пустой пакет сохраняет форму с дополнительной осью термов.

Raises:
    ImportError: NumPy не установлен.
    TypeError: Неподдерживаемая шкала, политика, функция, тип массива или представление чисел. Пользовательские, нормализованные и составные функции остаются скалярными.
    ValueError: Неверное значение `backend`, координаты, универсальные множества или степени принадлежности.
    ArithmeticError: Активная ветвь функции принадлежности не может быть вычислена.

Notes:
    Нормализация координат и степеней, преобразование в вероятности, нечёткий вывод и дефаззификация не выполняются. Для float-порогов сохраняется скалярное правило сравнения почти равных максимумов.
