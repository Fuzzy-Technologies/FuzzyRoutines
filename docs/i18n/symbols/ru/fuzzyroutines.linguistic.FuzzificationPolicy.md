Явная политика классификации с обработкой равных максимумов и минимальной уверенностью.

Attributes:
    tiePolicy: Выбор при равных или эквивалентных по допуску максимальных принадлежностях: `"first"`, `"last"` или `"all"`.
    minimumConfidence: При максимальной принадлежности не выше этого порога терм не выбирается. По умолчанию отклоняется только нулевое покрытие.
    tieTolerance: Абсолютная разность принадлежности с максимумом, считающаяся равенством.
