Неизменяемые выборочные сведения о принадлежностях в одной координате шкалы.

Attributes:
    coordinate: Конечная координата объявленной диагностической сетки.
    memberships: Одна степень принадлежности для каждого терма шкалы, в заданном порядке.
    membershipThreshold: Строгий порог активности для классификации пробелов и перекрытий.
