Проверяет, является ли значение допустимой степенью принадлежности из $[0, 1]$.

Args:
    value: Проверяемая степень принадлежности встроенного типа `int` или `float`; `bool` исключён.

Returns:
    `True` для поддерживаемого встроенного числа из замкнутого единичного интервала.
    Неподдерживаемый числовой тип или нечисловой ввод вызывают печать исторического диагностического
    сообщения и возврат `False`; поддерживаемое число вне интервала возвращает `False` без сообщения.
