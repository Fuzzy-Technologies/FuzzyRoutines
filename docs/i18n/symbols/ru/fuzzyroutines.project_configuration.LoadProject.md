Восстанавливает именованные модели и настройки из одного проекта формата v1 с ограничением размера.

Args:
    encoded: Данные проекта в кодировке UTF-8 и в выбранном формате.
    formatName: Явно выбранный формат входных данных. По умолчанию используется JSON.

Returns:
    Доступный только для чтения снимок с явно заданными значениями по умолчанию и сценариями, для которых вычисления ещё не выполнены.

Raises:
    ConfigurationError: Документ не удалось разобрать или проверить локально по правилам v1.
    ImportError: Не установлена необходимая дополнительная зависимость для конфигураций или YAML.
    ValueError: Выбранный формат не поддерживается.
