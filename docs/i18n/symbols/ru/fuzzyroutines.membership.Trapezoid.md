Возвращает кусочно-линейную трапецию с обычным порядком слева направо.

Конечные вещественные параметры должны удовлетворять `left < plateauStart <= plateauEnd < right`; логические значения отклоняются. Возвращаемая функция неизменяема и соблюдает граничные соглашения семейства, описанные в `MembershipFunction`.

Args:
    left: Левая опорная точка с нулевой принадлежностью.
    plateauStart: Включённая левая граница плато единичной принадлежности.
    plateauEnd: Включённая правая граница плато единичной принадлежности.
    right: Правая граница формы.

Returns:
    Проверенная неизменяемая аналитическая функция принадлежности.

Raises:
    ValueError: Параметры невещественные, неконечные или нарушают контракт семейства.
