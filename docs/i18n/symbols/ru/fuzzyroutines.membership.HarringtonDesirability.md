Возвращает принадлежность желательности Харрингтона exp(-exp(-x)).

Конструктор не принимает параметры. Неизменяемая возвращаемая функция принимает конечные вещественные координаты, исключая логические значения. Смысл её фиксированного масштаба координаты должна задавать модель предварительной обработки приложения.

Returns:
    Проверенная неизменяемая аналитическая функция принадлежности.
