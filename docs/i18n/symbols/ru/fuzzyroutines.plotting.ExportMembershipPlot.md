Сохраните данные скалярной функции принадлежности в виде научного графика без графической сессии.

Дискретные значения и функции с неизвестной непрерывностью показаны отдельными маркерами.
Для известных разрывов встроенных функций линии разделяются. Степени принадлежности
вычисляет скалярный API. На общем графике сохраняются порядок термов и единицы координат.

Args:
    source: Скалярное нечёткое множество, упорядоченная шкала или отдельная функция принадлежности.
    destination: Явный путь с расширением `.png`, `.jpg`, `.jpeg` или `.svg`.
    universe: Универсум, обязательный для отдельной функции принадлежности.
    displayWindow: Конечные возрастающие границы отображения. По умолчанию охватывают ограниченные универсумы термов; для одной точки оси расширяются.
    sampleCount: Число базовых отсчётов на каждом видимом непрерывном участке, не меньше двух.
    title: Заголовок графика и значение заголовка в метаданных SVG.
    coordinateLabel: Подпись координатной оси с известными единицами.
    formatName: Необязательный формат, который должен совпадать с расширением файла.
    background: Явный непрозрачный цвет `#RRGGBB`, обязательный для JPEG.
    transparent: Прозрачный фон холста и области построения для PNG или SVG.
    overwrite: Разрешение на атомарную замену файла.
    svgTextAsPaths: Сохранение текста SVG в виде контуров символов.

Returns:
    Абсолютный путь к сохранённому графику.

Raises:
    InvalidParameterTypeError: Неподходящий тип источника, универсума или координаты.
    InvalidParameterError: Неверное число отсчётов, подпись или параметр формата.
    InvalidDomainError: Неверный диапазон отображения, непригодная сетка или отсутствие отсчётов.
    PlotSamplingError: Ошибка скалярного вычисления в видимой точке.
    ImportError: Опциональный бэкенд Matplotlib недоступен.
    OSError: Не удалось сохранить файл, например из-за совпадения имён.
