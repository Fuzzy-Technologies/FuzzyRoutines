Возвращает точный слабый альфа-срез дискретного скалярного нечёткого множества.

Область содержит все объявленные координаты `x`, для которых `fuzzySet.Membership(x) >= alpha`. Непрерывные универсальные множества явно отклоняются: в текущей модели произвольная вызываемая функция принадлежности не имеет аналитической обратной функции или конечного исчерпывающего представления.

Args:
    fuzzySet: Скалярное нечёткое множество на дискретном универсальном множестве.
    alpha: Порог принадлежности для нестрогого альфа-среза в $[0, 1]$.

Returns:
    Упорядоченная дискретная область со всеми подходящими координатами.

Raises:
    TypeError: Типы аргументов не соответствуют дискретному контракту.
    ValueError: `alpha` не является конечным значением в $[0, 1]$.
