# Примеры переносимой конфигурации нечётких моделей

[English](README.md) · [简体中文](README.zh-CN.md)

В [ADR-0021](../../adr/0021-versioned-project-configuration.md) предложена
[схема версии 1](../../../fuzzyroutines/config-v1.schema.json). Установите
`fuzzyroutines[config]`, чтобы загрузить примеры самостоятельных моделей
через [`LoadModel`](../../site/content/ru/api/modern/configuration.md) и получить
канонические байты через `DumpModel`. Файлы открывает вызывающий код.
Пример проекта показывает встроенные модели, оформление и сценарии.
`LoadModel` принимает документы самостоятельных моделей.

- [Историческая шкала](fixtures/valid-historical-scale.json) сохраняет пять
  исходных термов, их коэффициенты, замкнутую единичную область, интервалы
  вычисления центроидов и выбор последнего терма при точном равенстве
  максимумов. Например, при входе `0.75` выбирается `High` со степенью
  принадлежности `1`.
- [Дискретная шкала](fixtures/valid-discrete-scale.json) задаёт три допустимые
  координаты. На них вычисляется аналитическая функция Харрингтона; значения
  между точками в дискретную область не входят.
- [Проект](fixtures/valid-project.json) содержит модель Мамдани `centroid`
  и модель Сугено `weighted`. Сценарий `quarter` выбирает `weighted` при
  `risk = 0.25`: силы срабатывания правил равны `0.875` и `0.125`, значения
  заключений — `0.25` и `0.625`, итог — `0.296875`. При том же входе модель
  Мамдани срезает симметричный треугольник, его центроид равен `0.5`. Заголовок
  графика, цвет и подпись единицы измерения не участвуют в расчётах.

Параметры модели меняют вычисления; подписи и цвета меняются в
`presentation`. В ссылках используется ID в соответствующей области
видимости: сценарий обращается к входу `risk`, хотя имя переменной в
исполняемой модели — `Risk`.

[Команда проверки схемы](README.md#checking-the-files) проверяет примеры
локально. [Пример с вызываемым объектом](fixtures/invalid-schema-callable.json)
не проходит проверку схемы: такой тип и путь импорта запрещены.
[Пример с отсутствующей ссылкой](fixtures/invalid-semantic-reference.json)
проходит проверку схемы. При вызове `LoadModel` ошибка указывает на
`/scales/score/terms/0/membership`, поскольку в модели нет определения
функции принадлежности с ID `missing`.
